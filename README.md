# python-fundamentals-for-ai-and-ml
A curated collection of Jupyter notebooks covering Python fundamentals, data analysis, and introductory machine learning. Built as a practical learning resource with hands on exercises, implementations, and examples for aspiring AI and ML developers.

## 📂 Opening Notebooks in Google Colab

**Quick Steps:**

1. **Download/Clone this repository** to your computer (or download individual `.ipynb` files)
2. **Go to [colab.research.google.com](https://colab.research.google.com)**
3. **Click `File` → `Open notebook`**
4. **Select the `Upload` tab** in the popup
5. **Click `Choose File`** and browse to your downloaded `.ipynb` file
6. **Select your notebook** and it will open in Colab!

**💡 Pro Tip:** After opening, go to `File > Save a copy in Drive` to keep your changes and access it anytime without re-uploading.
